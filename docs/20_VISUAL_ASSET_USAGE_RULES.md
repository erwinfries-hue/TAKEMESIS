# Visual Asset Usage Rules

## Official AXIA4 logo

Use:
`assets/brand/AXIA4_OFFICIAL_LOGO_REFERENCE.png`

For the production application, request or create a web-optimized transparent logo asset from the official source without changing its geometry, wording, colors, or flourish.

## One-pager

`assets/onepager/TEKMESIS_ONEPAGER_VISUAL_REFERENCE.png`

Use for:
- concept communication
- layout inspiration
- section hierarchy
- topic taxonomy presentation
- architecture presentation

Do not treat any text or data in the image as authoritative specification where it conflicts with written documents.

## Premium report images

Use for:
- premium look and feel
- navigation/hierarchy
- cards
- charts
- comparison layouts
- confidence panels
- source appendix
- AXIA4 placement

Do not copy:
- study names
- years
- sample sizes
- effect sizes
- citations
- report page counts
- factual conclusions

All factual report content must come from validated source adapters and provenance.
