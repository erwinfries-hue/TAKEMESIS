## Important asset warning

The supplied one-pager and premium-report images are **visual design references only**.

They may contain:
- illustrative data,
- placeholder study names,
- abbreviated references,
- typographical imperfections,
- values that have not been independently validated.

Claude must never copy factual study claims, numbers, citations, effect sizes, or bibliographic details from the images into the product. All live report content must be derived from verified scholarly sources.
