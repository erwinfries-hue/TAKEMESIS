# Design System, Brand, and Assets

## Brand

TEKMESIS:
- premium
- evidence-led
- calm
- intelligent
- accessible
- transparent

AXIA4:
- use exact official logo reference:
  `assets/brand/AXIA4_OFFICIAL_LOGO_REFERENCE.png`

Do not redraw or approximate the AXIA4 logo in production assets if an exact usable asset can be supplied.

## Palette

Use:
- deep navy
- teal/cyan
- white/light grey
- restrained AXIA4 gold
- red/orange only for warnings or mixed/negative findings

## UI principles

- visible source links
- uncertainty not hidden
- clear free versus paid distinction
- premium report preview
- topic inspiration
- responsive layouts
- no color-only meaning
- full keyboard access
- WCAG 2.2 AA-oriented
- print-friendly report
