# Premium Evidence Report Specification

## Product promise

The Premium Report must feel deep, structured, credible, and materially more valuable than the free teaser.

## Format

- primary: responsive online report
- print-friendly A4 layout
- browser “Save as PDF” in P0
- automatic branded PDF may be P1
- target print-equivalent depth: approximately 8–12 pages when evidence supports it
- shorter report only when clearly disclosed before purchase

## Required report structure

### 1. Cover and Executive Summary
- TEKMESIS and AXIA4 branding
- original question
- interpreted research question
- report date/version
- evidence-confidence label
- 5–7 key findings
- search/inclusion KPIs
- one high-level visual

### 2. Question, Scope, Target Context, and Method
- what the report investigates
- intended audience/context
- question framework
- databases/sources
- search date
- selection process
- inclusion/exclusion criteria
- what the report does not provide

### 3. Evidence Landscape
- study-type distribution
- publication timeline
- methods/interventions represented
- populations and contexts
- included-study list
- coverage limitations
- retractions/corrections status where detectable

### 4. Study Comparison
- study
- year
- design
- participants
- population/context
- intervention/exposure
- comparator
- duration
- outcome
- effect estimate where explicitly reported
- key finding
- limitations
- evidence contribution
- source link

### 5. Detailed Study Profiles
For each key study:
- verified citation
- study question
- design
- population/sample
- intervention/exposure
- comparator
- outcomes
- result
- uncertainty
- limitations
- funding/conflicts where available
- source/provenance

### 6. Integrated Synthesis
- what evidence overall suggests
- where studies agree
- where they differ
- why they differ
- key limitations
- what remains uncertain
- applicability to the original question

### 7. Evidence Confidence
- confidence label
- transparent dimensions
- why not higher
- why not lower
- data completeness
- consistency
- directness
- precision when available
- risk indicators

### 8. Practical Interpretation
- evidence-based orientation
- possible implications
- conditions/context where findings may differ
- no individualized professional advice
- cautious actionable framing only where appropriate

### 9. Open Questions and Sources
- unresolved research questions
- complete source list
- DOI/PMID/OpenAlex/Crossref identifiers where available
- direct source links
- methodology/version/disclaimer

## Premium visual system

Use the images in:
`assets/premium_report_visual_reference/`

as style references for:
- page hierarchy
- navy/teal/gold palette
- premium cards
- evidence badges
- comparison matrices
- source visibility
- report navigation
- clear charts

Do not use their study content as factual input.

## Quality requirements

- no dense wall of text
- no illegible desktop-only tables
- mobile cards for comparisons
- all visuals accessible with text alternatives
- every factual claim traceable
- missing data visible
- AI-generated text labeled
- report depth disclosed before checkout
